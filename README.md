# 🔐 Password Manager

A full-stack password manager built with **React, Tailwind CSS, Express.js, and MongoDB**.

This project allows users to manage and organize saved credentials through a clean and responsive web interface. It was built as a full-stack development project to practice frontend development, REST APIs, database integration, deployment, and CRUD operations.

## 🌐 Live Demo

🚀 **[View the Live Password Manager](https://passman-by-chiragackerman.vercel.app/)**

> The frontend is deployed on Vercel, while the backend is deployed on Render and the database is hosted on MongoDB Atlas.

---

## ✨ Features

- 🔐 Add and manage saved credentials
- ✏️ Edit existing credentials
- 🗑️ Delete saved credentials
- 👁️ Show/hide password fields
- 📋 Copy credentials easily
- 🔎 Search and manage saved entries
- 📱 Responsive user interface
- ⚡ Interactive React frontend
- 🗄️ MongoDB database integration
- 🔌 RESTful API using Express.js
- 🌍 Deployed frontend and backend
